# 🗄️ Índice de Estudio: Base de Datos (MySQL)

---

## 🟢 NIVEL BÁSICO (`01_Nivel Básico`)
- [01] **¿Qué es una base de datos?** — Conceptos fundamentales (tablas, registros, campos, claves).
- [02] **Instalación y configuración de MySQL** — MySQL Server, Workbench, conexión.
- [03] **Tipos de datos en MySQL** — `INT`, `VARCHAR`, `DATE`, `DECIMAL`, `TEXT`, etc.
- [04] **Creación de bases de datos y tablas** — `CREATE DATABASE`, `CREATE TABLE`.
- [05] **Operaciones CRUD básicas** — `INSERT`, `SELECT`, `UPDATE`, `DELETE`.
- [06] **Cláusulas fundamentales** — `WHERE`, `ORDER BY`, `LIMIT`, `DISTINCT`.
- [07] **Funciones básicas** — `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, funciones de texto y fecha.
- [08] **NULL y valores por defecto** — Manejo de nulos, `DEFAULT`, `NOT NULL`.

---

## 🟡 NIVEL MEDIO (`02_Nivel Medio`)
- [] **Claves primarias y foráneas** — `PRIMARY KEY`, `FOREIGN KEY`, integridad referencial.
- [] **Restricciones (Constraints)** — `UNIQUE`, `CHECK`, `AUTO_INCREMENT`, `ON DELETE/UPDATE CASCADE`.
- [ ] **Relaciones entre tablas** — 1:1, 1:N, N:M y tablas intermedias.
- [ ] **JOINs** — `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `CROSS JOIN`, `SELF JOIN`.
- [ ] **Subconsultas (Subqueries)** — En `SELECT`, `WHERE`, `FROM`, correlacionadas.
- [ ] **Agrupaciones** — `GROUP BY`, `HAVING` (diferencias con `WHERE`).
- [ ] **Índices** — Qué son, tipos, cuándo usarlos, impacto en rendimiento.
- [ ] **Modificación de estructuras** — `ALTER TABLE`, `DROP`, `TRUNCATE`.
- [ ] **Vistas (Views)** — Creación, uso y limitaciones.
- [ ] **Funciones de ventana (Window Functions)** — `ROW_NUMBER`, `RANK`, `PARTITION BY` (intro).

---

## 🔴 NIVEL AVANZADO (`03_Nivel Avanzado`)
- [ ] **Procedimientos almacenados** — `CREATE PROCEDURE`, parámetros, lógica.
- [ ] **Funciones almacenadas y triggers** — `CREATE FUNCTION`, `CREATE TRIGGER`.
- [ ] **Transacciones** — `BEGIN`, `COMMIT`, `ROLLBACK`, ACID, `SAVEPOINT`.
- [ ] **Control de concurrencia y bloqueos** — Locks, niveles de aislamiento.
- [ ] **Optimización de consultas** — `EXPLAIN`, análisis de planes de ejecución.
- [ ] **Índices avanzados** — Compuestos, covering index, full-text.
- [ ] **Particionamiento de tablas** — Tipos y casos de uso.
- [ ] **Seguridad y usuarios** — `CREATE USER`, `GRANT`, `REVOKE`, roles.
- [ ] **Backup y recuperación** — `mysqldump`, restauración, estrategias.
- [ ] **Normalización y diseño** — 1FN, 2FN, 3FN, BCNF, desnormalización.
- [ ] **JSON en MySQL** — Tipos JSON, funciones, consultas.
- [ ] **Réplicas y alto rendimiento** — Replicación maestro-esclavo (conceptual).
